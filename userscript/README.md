## ハニカムシーンデータコンバーター

[ハニカム公式シーンアップローダー](https://honeycome-uploader.illgames.jp/list/scene) のシーン一覧ページで動作するユーザースクリプトです。

シーンのダウンロードリンクをクリックすると、ファイルをダウンロードする代わりにパネルが開き、シーンに含まれるキャラクターの内訳を確認したり、そのキャラを別のタイトル向けに変換しダウンロードすることができます。

---

## 使い方

1. シーン一覧ページのダウンロードリンクをクリック
2. 開いたパネルでシーン情報が自動解析される
3. 「HC へ保存」(ハニカム)「SV へ保存」(サマすく)「AC へ保存」(アイコミ)のいずれかをクリックしてダウンロード
4. パネル外をクリックすると閉じる

## 主な機能

### シーン情報の表示
- シーンタイトル・バージョンを表示
- 含まれるキャラクターの総数と、タイトル別の内訳 (ハニカム / サマすく / アイコミ) をバッジで表示
- ZIP圧縮されたシーンを解凍

### シーンの変換＆ダウンロード
シーン内のキャラを別タイトル向けに変換して PNG ファイルとしてダウンロードできます。

| ボタン | 変換先 |
|--------|--------|
| **HC へ保存** | ハニカム |
| **SV へ保存** | サマバケ！すくらんぶる |
| **AC へ保存** | アイコミ |

シーン内のキャラがすでに変換先タイトルのものだった場合は、変換をスキップしてそのままダウンロードします。

### 末尾HTMLの除去
公式アップローダーからダウンロードしたシーンファイルには不要なHTMLデータが末尾に付いていることがあります。  
パネル内のチェックボックスで確認・除去してからダウンロードできます（ファイルサイズも表示）。

---

## 注意事項

- 変換処理はブラウザ内で完結します（ファイルは外部サーバーに送信されません）
- 変換に対応しているのは HC / SV / AC シリーズのキャラが含まれるシーンのみです
